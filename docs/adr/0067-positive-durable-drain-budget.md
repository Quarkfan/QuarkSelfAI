# ADR-0067：持久化唤醒的单轮预算必须为正整数

状态：Accepted（2026-08-25）

## 问题

`DurableWakeScheduler` 用 `maxPasses` 限制一次唤醒连续处理的轮数，让 backlog 能快速排空，同时定期把执行权交还给
事件循环。此前该配置没有边界校验；当值为 `0`、负数或非整数时，drain 不会执行持久化任务，却会保留
`wakePending` 并立即重新调度，形成没有业务进展的高频空转。

## 决策

- 显式配置的 `maxPasses` 必须是正的安全整数；省略时继续使用默认值 `100`；
- 无论调度器是否启用，都在构造时校验配置，避免潜伏配置在切换启用后才暴露；
- `maxPasses` 只控制单次 drain 的公平性，不替代 10 分钟恢复扫描，也不改变持久化存储的真源地位。

## 结果

配置错误会在组件装配阶段快速失败，不能退化为即时轮询风暴。有效配置的唤醒合并、精确 deadline、恢复扫描和
dispose 语义保持不变。
