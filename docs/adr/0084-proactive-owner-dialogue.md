# ADR 0084：受限的主动了解与协作对话

## 背景

助手已经能从任务、通知和本人纠正中被动学习，但无法主动补齐那些长期反复造成误判、又不能从飞书或本地资料
直接读出的协作信息。简单增加定时寒暄会制造新的打扰，也会把 compatibility host 变成长期业务核心。

## 决策

- 长期 `proactive-dialogue-policy` 只拥有有界上下文、输出校验、问题状态和 owner-stated insight 语义。
- compatibility adapter 只做现网调度、Claude 主判断、Codex 兜底与飞书 Card 2.0 输入接线；DSH-native 切换时
  与 collaboration-learning 使用同一冻结点和单一调度器。
- 模型只有在价值评分至少 75 时才能提问，并选择 12–168 小时后的下一次评估建议。运行时额外强制工作时段、
  至少 48 小时冷却、同一时间一个问题、72 小时未答静默过期。
- 问题不能索取可自行读取的信息、凭证或敏感隐私，也不能把批准、外联或执行授权伪装成聊天。
- 卡片输入和明确回复都能关联原问题；回答作为可纠正的 `owner-stated` insight 进入后续语义判断。它不会自动
  激活策略或授权调研、外联、发布、配置和业务写入。

## 结果

助手可以自然地主动了解用户，同时主动交流仍受通知降噪和授权安全壳约束。知识不会只留在聊天记录里，也不会
因当前兼容运行形态形成无法迁移的新旧双写。
