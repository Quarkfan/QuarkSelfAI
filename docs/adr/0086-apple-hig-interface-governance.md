# ADR 0086：Apple HIG 驱动的界面治理

## 背景

控制台已经形成独立视觉，但缺少跨页面、跨会话和未来插件都必须遵守的设计质量门禁。只在提示词里要求“像苹果”会造成表面模仿、页面间漂移和可访问性退化，也无法通过自动检查约束后续实现。

## 决策

- 助手自有 UI 以 Apple Human Interface Guidelines 的目的、掌控感、责任、熟悉度、简洁、精工，以及层级、和谐、一致性为设计基线。
- 采用“原则 → 语义 token → 交互基线 → 页面表达”四层结构。原则与无障碍是硬门禁；页面构图和视觉气质保留创造空间，不把规则变成固定模板。
- 材质只区分导航、工具和临时浮层，内容层保持清晰；颜色只作辅助信息；动效必须有功能目的并支持减少动效。
- QuarkSelfAI 不复制 Apple 商标、专有图标或产品外观。系统字体、平台交互习惯和公开 HIG 原则用于提升原生感，品牌识别继续由 QuarkSelfAI 自己承担。
- 新增界面必须通过静态契约测试、完整项目检查和真实窗口视觉复核。违反键盘焦点、交互热区、减少动效、语义颜色或窄屏适配时不得交付。

## 边界与演进

该决策只约束 QuarkSelfAI 和助手自有界面，不改变 DSH/Cordis 内核、消息消费者、数据真源或外部 BlackLake 产品代码。Apple HIG 更新由能力进化机制定期核验；可以更新 token 和表现，但不能静默降低可访问性和用户掌控门禁。

实现标准见 `docs/design/apple-human-interface-standard.md`。回滚单个视觉实现不撤销设计治理；如需变更原则，必须用新的 ADR 说明原因、兼容影响和迁移方式。
