# ADR 0090：可移植个人助手与工作领域隔离

状态：Accepted（2026-09-05）

## 背景

QuarkSelfAI 已能在当前电脑运行，但代码、运行状态、账号身份和工作知识分散在 Git、`var`、多个 CLI 配置及
BlackLakeWork 外部目录。仅 clone 仓库不能恢复助理连续性；同时 BlackLake 专用路由已进入主仓库和 profile，
使个人助手主线依赖当前雇主工作环境。

## 决策

1. QuarkSelfAI 正式定义为独立、本地优先且可异机恢复的个人助手产品。
2. Git 仓库保存程序真源，加密恢复包保存最小持久状态，密码管理器/重新登录保存身份秘密；三者不互相替代。
3. 恢复实例默认关闭消费者和外部写 effects，通过数据、身份和单写者门禁后才切换。
4. BlackLake 业务能力迁移为私有、可卸载的 work integration pack；核心不得依赖其存在。
5. 外部 DevOps 资料只能作为周期性候选。采纳内容必须记录 provenance/许可并复制、去业务化、测试后成为本地资产。
6. 当前在用 BlackLake 适配器不立即删除；先完成依赖清单、等价 pack 和受控切换，以免破坏现网。

## 结果

- 新增项目章程、恢复规范、数据/身份清单、资源申请与机器可读 recovery manifest。
- 在 owner 提供异机目标和加密接收者前，恢复审计必须保持未就绪，不能伪装成功。
- 后续备份、恢复脚本和领域拆分分别进入 Phase 2/3，并通过真实干净终端演练完成 Phase 4。
- 现有 BlackLake 模块被明确登记为待迁移耦合；对其删除或改 composition 仍需独立批准。

## 替代方案

- **把整个用户目录同步到云盘**：拒绝。会复制大量缓存、遥测和敏感历史，且缺乏一致性与版本兼容保证。
- **只依赖飞书/滴答重新拉取**：拒绝。审批、幂等 checkpoint、策略、DSH 状态和工作流不以这些系统为真源。
- **直接从主线删除 BlackLake 代码**：暂缓。它仍参与当前运行，直接删除违反单消费者与可回滚要求。
