# ADR 0003：本地优先个人助手

状态：已接受  
日期：2026-08-22

## 背景

QuarkSelfAI 主要由单个用户在个人电脑上长期运行。它不仅处理飞书消息和滴答投影，还需要在用户授权的
前提下访问本地代码仓库、资料目录、Codex/Claude Code 会话及本机 CLI。服务器部署需要被支持，但不是
产品的默认运行环境，也不能成为本地能力的最低公分母。

## 决策

1. 产品主形态是本机单实例守护进程：默认使用 SQLite、回环 Web 控制台、本机 DSH 和本机 executor。
2. 本地文件访问是一等能力，但不是全盘权限。`ASSISTANT_WORKSPACE_ROOTS` 显式列出最小授权目录；未配置
   时只允许启动目录，禁止以 `/` 或用户主目录作为隐式默认值。
3. 所有 executor、兼容 Provider 和未来文件插件共用 `WorkspacePolicy`。已有路径解析真实路径，新建路径
   解析真实父目录，阻止目录穿越和符号链接逃逸。
4. 只读动作可在白名单内直接执行；工作区写入和外部写入必须进入 durable action/approval 链路。批准绑定
   到具体 action，不能成为永久的全局写权限。
5. 本地文件内容默认留在本机。飞书、滴答、远端 PostgreSQL 和可选服务器只接收必要的意图、状态、审计
   元数据及结果摘要；具体文件上传必须由用户针对该动作明确批准。
6. 服务器和容器是可选形态。纯控制面使用 `ASSISTANT_EXECUTION_MODE=remote`，不得声称能够直接访问个人
   电脑文件；若以后需要远端控制面协同本机文件，新增受限本机 worker 协议，而不是挂载或同步整个主目录。
7. 服务器适配不得删除、弱化或绕过本机 LaunchAgent、SQLite、桌面会话续接、本机 CLI 和 workspace
   policy。任何会改变这些边界的重构都属于架构破坏风险，执行前必须由常东旭决定。

## 结果

- 默认安装路径简单且适合个人长期运行；断网时仍能处理不依赖外部服务的本地工作。
- 文件能力保持强，但暴露范围可解释、可审核，且不会因启用服务器兼容能力自动扩大。
- PostgreSQL、systemd 和容器仍保留为团队化或服务器化扩展路径，却不支配个人助手的核心设计。

## 验证要求

- 运行时配置测试必须证明默认值为 `local + sqlite + loopback`。
- workspace policy 测试必须覆盖白名单内访问、目录穿越和符号链接逃逸。
- 兼容消费者启动前必须验证其 workspace 位于白名单内。
- 控制台与日志不得返回文件正文或完整白名单路径。
- 本地发布至少完成 LaunchAgent 渲染/校验、DSH profile 启动、健康检查、优雅停止和 SQLite 重启恢复。
