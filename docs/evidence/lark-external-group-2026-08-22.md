# 飞书外部群属性只读核验（2026-08-22）

## 目的

确认飞书 CLI 能否准确读取典型外部群“油脂客户沟通群”的外部属性，从而让自动追问和回复门禁使用
上游群属性，而不是依赖群名或成员推断。

## 执行边界

- 身份：已授权用户身份（`--as user`）。
- 操作：`lark-cli im +chat-search` 只读群搜索，关闭按成员名匹配。
- 结果：命中唯一正常群，标准字段 `external` 为 `true`。
- 未执行：未读取群消息、未列出成员、未发送消息、未修改群设置。
- 首次调用因执行沙箱 DNS 不可用失败；同一只读命令在获准联网后成功。这不是飞书授权或 CLI 故障。

## 结论

当前 lark-cli 和用户授权能够准确取得该群的 `external=true`。运行时必须继续执行 fail-closed：查询失败、
字段缺失或无法确认时，一律视作不可外联，只向常东旭提供建议，不在原群追问或正式回复。
