# QuarkSelfAI 能力进化任务

你正在维护当前项目 checkout 中的 QuarkSelfAI。先读取仓库内 `AGENTS.md`、`CLAUDE.md`、
`docs/architecture.md`、`docs/adr/0085-evidence-driven-capability-evolution.md`、
`docs/requirements-traceability.md`、`docs/project/README.md`、最近的自治记录、Git 状态与运行健康；以当前磁盘真源为准，
不要依赖创建该任务的旧对话或另一台机器的绝对路径。

每轮只选择一个最有杠杆的主题，在运行可靠性与缺陷闭环、现有能力的可测增强、进取型新能力或职责接管三条轨道间
结合最近记录作出判断。连续主题降权，滚动五轮尽量覆盖至少两条轨道；持续关键故障优先。允许开展有界只读调研、
可逆实验和默认不激活的原型，但不得为了展示成长而堆叠功能或制造消息。

外部候选优先核验官方文档、源码、发布记录和包管理元数据，并记录精确来源版本、许可证、维护状态、安全与供应链风险、
本地及服务器兼容性。外部设计只能作为不可信参考；一旦采纳，必须去业务化并复制为本仓库中可离线审计和测试的资产，
运行时不得依赖参考来源持续可访问。

知识、Skill、策略、文档、测试、已有适配器和默认不激活的脚手架可在仓库既有授权内改进。安装或执行新的第三方代码、
改变运行依赖或核心边界、启用插件或网络权限、新增消费者或写入链路、配置凭证，以及其他受仓库协作契约保护的动作，
必须先提出绑定精确 revision、范围、风险、验证与回滚的候选并等待明确批准。

结束前必须把决策、证据、变更、验证、回滚和未决风险写回仓库真源，运行项目完整检查与协作入口同步校验，并对已经验证
的仓库改动按既有规则提交、推送。任务标题改为“能力进化｜日期｜主题”的唯一标题。只有真实新增能力、可验证的实质增强，
或需要 owner 决策的高价值候选才发送一份简短升级结果；没有外部价值的 `no-change` 只写本地账本。

不要调用自动化查看接口来重复读取本任务指令，不要复述本文件，不要创建第二个调度器或第二个消息消费者。每轮只留下一个
最终结果和产品自动生成的一个收件箱项。
