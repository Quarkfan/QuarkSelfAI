# 自然语言策略

## 目标

常东旭只需要描述期望，不需要学习命令或 JSON。例如：

> 重庆平伟群里，只有明确 @我 且包含截止时间的消息才实时提醒；其他消息进入当日汇总。

系统不会每次收到消息都把这段话重新交给模型。owner 私聊总控调用 Claude Code/Codex 将它编译为受限
`PolicyDocument`，本地验证器拒绝未知字段、任意表达式、脚本、外部调用和过深条件，然后使用最近的脱敏事件样本重新模拟。

## 生效流程

1. 保存原始自然语言，生成新的 draft revision。
2. 确定性验证 DSL，不信任模型生成的模拟数字。
3. 用本地样本计算命中数、静默/汇总/实时数量以及紧急消息误抑制数。
4. 策略若会静默、忽略任务或改变回复方式，必须通过飞书卡片明确确认。
5. `urgentSuppressedCount > 0` 时禁止激活，必须先缩小范围或提供单独的安全覆盖设计。
6. 激活只修改 `active_revision`；旧 revision 永久保留，可审计和回滚。

## 当前 DSL

允许的事实限定为聊天类型、是否外部群、会话/发送人 ID、消息文本、是否 @本人、是否包含截止时间、关系类型、业务标签、当前注意力和紧急度。效果限定为：

- 注意力：不变、静默、批量汇总、实时；
- 滴答投影：不变、忽略、创建或更新；
- 回复：禁止、只生成草稿、向本人询问；
- settle window 与少量标签。

策略不能直接发送消息、调用 shell、修改文件、执行 SQL 或选择秘密字段。

## 当前完成度

DSL、验证器、模拟器、SQLite/PostgreSQL 版本表和控制台策略视图已经完成。自然语言 compiler 与 owner 私聊总控尚未迁移，因此该能力在接管门禁中仍为 `partial`，不能据此切换现网。
