# 本地 Skill 按需发现：第一批实施计划

状态：2026-10-12，待独立复评；仅离线元数据，不挂载运行时。

## 目标与范围

沿用现有 `CapabilityDiscoveryIndexV1`，把用户明确指定的本地 Skill 根目录编译成轻量候选。只在显式刷新时扫描；平常查询复用已编译索引，避免每个任务全量扫描和正文进上下文。与第一方能力候选、外部来源共用同一检索入口，不建立手工平行目录。示例由合成 fixture 验证；产品不得依赖 BlackLake 私有 Skill 或原型仓库。

## 实施顺序

1. 增加有界、只读的本地采集器：调用方传入唯一逻辑根 ID 与精确路径；每根仅扫描直接子目录的 `SKILL.md`。拒绝符号链接、越界路径、重复 ID、超限文件/目录和不完整 frontmatter。只提取 `name`、`description` 与元数据摘要，不保存正文或绝对路径到发现结果。
2. 现有索引接受可选的本地 Skill 描述符，统一返回 `executable=false` 的元数据引用；inspect 才给出摘要、版本摘要和不可执行原因。默认索引编译保持原有签名和结果兼容。
3. 补合成单测、操作说明与 module-catalog 所有权；运行类型、测试、架构及完整检查，提交后再跑架构检查。

## 非目标与验收

本批不安装、执行、激活或更新任何 Skill；不读 references、脚本和远端内容；不自动读取全局 Skill 目录；不将路径、正文或私有名称送往云端；不宣称多租户授权过滤、语义召回和三执行器路由已完成。合成测试必须覆盖显式根、普通 Skill、重复 ID、symlink 与超限、正文不进入输出。上线仍需独立审批、scope policy、revision 绑定、负迁移评估及跨执行器回放。
